# auto-ai-blog

AI副業ブログの完全自動運営システム。

## 概要

7人のAIエージェント（CEO、SEO、Writer、Designer、Linker、Editor、Analyst、Marketer）が協力してブログ記事を自動生成・投稿します。

## 公開サイト

- **ブログ**: https://garyohosu.github.io/auto-ai-blog/
- **GitHub**: https://github.com/garyohosu/auto-ai-blog

## エージェント構成

| ID | 役割 | 担当 |
|----|------|------|
| VE-001 | CEO | 戦略統括 |
| VE-002 | SEO Specialist | キーワード分析 |
| VE-003 | Writer | 記事執筆 |
| VE-004 | Designer | OGP画像作成 |
| VE-005 | Linker | 内部リンク最適化 |
| VE-006 | Editor | 品質管理 |
| VE-007 | Analyst | データ分析 |
| VE-008 | Marketer | SNSマーケティング |

## 技術スタック

- **フレームワーク**: Jekyll (GitHub Pages)
- **自動化**: GitHub Actions
- **トリガー**: Sakura VPS cron
- **分析**: Google Analytics 4

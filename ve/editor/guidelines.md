# Editorial Guidelines

## 品質基準
- 字数: 3000字以上（ピラー記事は5000字以上）
- 比較表: 3つ以上のツールを比較
- FAQ: 3問以上
- CTA: 1つ以上（アフィリエイトリンクまたは関連記事）

## 公開禁止コンテンツ
- 未確認の統計・数値の断定
- 競合サービスへの誹謗中傷
- 個人情報を含むコンテンツ
- ニュース・速報（1ヶ月以内に陳腐化するもの）

## evergreen 判定基準
- 1年後も検索される内容か？ → YES なら OK
- 「最新」「速報」が入っていないか？ → 入っていれば要注意
- 悩み解決 / 比較 / 手順 のいずれかか？ → YES なら OK

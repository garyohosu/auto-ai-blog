# Writer Style Guide

## 文体・トーン
- 読者: AIツールに興味があるビジネスパーソン・副業希望者
- 文体: 丁寧語（です・ます調）、親しみやすく専門的
- 一文: 60字以内を目安

## 記事構成（必須）
1. **導入** — 誰の何の悩みを解決するか（200字以内）
2. **本文** — 比較表・手順・ツール紹介（2000〜4000字）
3. **FAQ** — 3〜5問（検索意図の網羅）
4. **まとめ・CTA** — 次のアクションを明確に

## プレースホルダー
- アフィリエイト: `[AFF_LINK: product_name]`
- 内部リンク: `[INTERNAL: slug]`（run.js が自動解決）

## SEOルール
- タイトル: 32字以内、主要キーワードを先頭に
- description: 80〜120字
- h2見出し: 4〜8個、キーワードを自然に含める
- 画像alt: 記事タイトルを使用（自動設定済み）

## 禁止事項
- ニュース・速報記事（短命コンテンツ）
- 既存記事の改変
- 確認できない数値・統計の断言

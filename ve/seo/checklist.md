# SEO Checklist

## 記事公開前チェック
- [ ] タイトルに主要キーワードが含まれている
- [ ] description が 80〜120字
- [ ] h1 は1つのみ（タイトル）
- [ ] h2 が4個以上ある
- [ ] アイキャッチ画像が設定されている（`image:` front matter）
- [ ] 内部リンクが1〜5本ある
- [ ] `[AFF_LINK:]` プレースホルダーが実URLに置換されている（手動）
